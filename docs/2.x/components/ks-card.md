# Card

<Demo name="PageKsCard" />

## Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| <code>header</code> | <code>String</code> |  | Text to display in the card header |
| <code>light</code> | <code>Boolean</code> | <code>false</code> | Applies the light ks-card style |

## Slots

| Name | Description |
| --- | --- |
| <code>header</code> | Slot rendered in the ks-card-header |
| <code>footer</code> | Slot rendered in the ks-card-footer |
