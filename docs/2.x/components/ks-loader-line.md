## Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| <code>height</code> | <code>String</code> | <code>5px</code> | The height of the loader line |
| <code>show</code> | <code>Boolean</code> | <code>False</code> | If the loader is visible |
| <code>absolute</code> | <code>Boolean</code> | <code>False</code> | Allows the component to be positioned absolute |
| <code>zIndex</code> | <code>Number</code> | <code>1</code> | Change the z-index property |
