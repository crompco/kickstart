# Loader Spinner

<Demo name="PageKsLoaderSpinner" />

## Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| <code>show</code> | <code>Boolean</code> | <code>False</code> | If the loader is visible |
| <code>height</code> | <code>String</code> | <code>auto</code> | The height of the loader |
| <code>size</code> | <code>String</code> | <code>NULL</code> | The size of the spinner: tiny, small, medium, large, x-large |
| <code>color</code> | <code>String</code> | <code>NULL</code> | The color of the spinner |
| <code>bg</code> | <code>String</code> | <code>NULL</code> | The background color or the color of the rail that the spinner is on |
