# Panel

<Demo name="PageKsPanel" />

## Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| <code>header</code> | <code>String</code> |  | Text to display in the panel header |
| <code>light</code> | <code>Boolean</code> | <code>False</code> | Applies the light ks-panel style |

## Slots

| Name | Description |
| --- | --- |
| <code>header</code> | Slot rendered in the ks-panel-header |
| <code>footer</code> | Slot rendered in the ks-panel-footer |
