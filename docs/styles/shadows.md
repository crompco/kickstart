# Shadows Utilities

## Classes

| Name | Definition |
| --- | --- |
| <code>shadow-sm</code> | <code>box-shadow: 0 1px 1px rgba(0, 0, 0, 0.2);</code> |
| <code>shadow</code> | <code>box-shadow: 0 1px 3px 0 rgba(0, 0, 0, 0.2);</code> |
| <code>shadow-lg</code> | <code>box-shadow: 0 5px 15px -2px #aaa;</code> |
| <code>shadow-none</code> | <code>box-shadow: none;</code> |

#### Default Box Shadow Map

```sass
$shadows: (
    'shadow-sm': 0 1px 1px rgba(0, 0, 0, 0.2),
    'shadow': 0 1px 3px 0 rgba(0, 0, 0, 0.2),
    'shadow-lg': 0 5px 15px -2px #aaa,
    'shadow-none': none,
);
```
